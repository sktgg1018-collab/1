# 书脉 BookGraph

一个无需后端即可运行的书籍知识图谱原型。

## 功能
- 粘贴书名、简介与出版信息后，自动提取书籍、作者、角色、主题、出版社、年份实体；
- 自动建立「作者创作书籍」「角色属于作品」「主题关联书籍」「出版社/年份出版书籍」等关系；
- 按实体名称、实体类型、关系类型检索；
- 交互图谱：点击查看详情、双击展开一跳关系、连续选择两个节点显示最短路径、关系方向与节点标签切换；
- 内置《三体》可体验示例。

## 使用
直接打开 `index.html`；或使用任意静态服务器预览，例如：

```bash
npx serve .
```

> 当前自动提取使用浏览器内置规则，适合作为第一版原型。后续可将 `extract()` 对接 NLP/LLM 服务，并用 Neo4j、ArangoDB 或图数据库 API 存储持久化图谱。
